# Bulgarian Bag Timer

불가리안 백(케틀벨백) 운동을 위한 macOS용 인터벌 타이머입니다.
뽀모도로 타이머처럼 원형 진행 링과 큰 숫자로 남은 시간을 보여주며, **운동 → 휴식**을 1라운드로 하여 라운드 수를 설정하고 반복할 수 있습니다.

## 주요 기능

- 운동/휴식 시간을 분:초 단위로 설정
- 라운드 수 설정 (1~99)
- "마지막 휴식 생략" 옵션 (마지막 라운드 운동 후 바로 종료)
- 시작 / 일시정지 / 계속 / 리셋
- 라운드마다 원형 진행 링 색상 변경 (운동: 주황빨강, 휴식: 파랑, 완료: 초록)
- 라운드가 20개 이하면 라운드별 진행 점(dot) 표시
- 단계가 바뀔 때, 그리고 전체 운동이 끝났을 때 macOS 기본 사운드로 알림

## 실행 방법

이 앱은 macOS에 기본 내장된 Python3 + tkinter만 사용하므로 별도 설치 없이 바로 실행할 수 있습니다.

1. 터미널(Terminal)을 엽니다.
2. 이 프로젝트 폴더로 이동합니다.

   ```bash
   cd ~/Desktop/"Claude Code"/bulgarian-bag-timer
   ```

3. 아래 명령으로 실행합니다.

   ```bash
   python3 bulgarian_bag_timer.py
   ```

실행하면 타이머 창이 뜹니다. 운동/휴식 시간과 라운드 수를 원하는 대로 조정한 뒤 **시작** 버튼을 누르면 됩니다.

### 더블클릭으로 실행하고 싶다면

터미널 없이 Finder에서 더블클릭으로 실행하고 싶다면, 다음 명령으로 실행 권한을 준 뒤 파일을 더블클릭하세요 (파일 앞에 `#!/usr/bin/env python3` 셔뱅이 이미 포함되어 있습니다).

```bash
chmod +x bulgarian_bag_timer.py
```

다만 macOS Finder에서 `.py` 파일은 기본적으로 텍스트 편집기로 열리도록 연결되어 있을 수 있습니다. 그 경우 터미널에서 실행하는 방법(위 3번)을 사용하는 것이 가장 간단합니다.

### Python3이 없는 경우

macOS Catalina 이상에는 기본적으로 Python3이 없을 수 있습니다. 이 경우 다음 중 하나로 설치하세요.

```bash
brew install python-tk
```

또는 [python.org](https://www.python.org/downloads/macos/)에서 공식 설치 파일을 받아 설치합니다.

## 사용 팁

- 실행 중에는 설정값(시간, 라운드)이 잠깁니다. **리셋**을 눌러야 다시 조정할 수 있습니다.
- **일시정지** 후 **계속**을 누르면 남은 시간부터 이어서 진행됩니다.
- 완료되면 초록색으로 "완료!" 표시와 함께 완료 알림음이 울립니다. **다시 시작**을 누르면 처음부터 재설정됩니다.
